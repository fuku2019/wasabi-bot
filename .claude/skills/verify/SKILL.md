---
name: verify
description: lint・フォーマット・テストをまとめて実行して結果を報告する。コミット前やコード変更後の確認に使う。
---

リポジトリ直下で以下を順に実行し、途中で失敗しても最後まで実行する。

1. `uv run ruff check .`
2. `uv run ruff format --check .`
3. `uv run pytest -q`

結果を短く報告する。失敗があれば、エラー内容と該当箇所（`file:line`）を示す。lint やフォーマットの自動修正は、ユーザーに頼まれた場合だけ行う。

コードの変更でコマンド・キーワード・文言・挙動が変わっている場合は、`README.md` が更新されているかも確認する。
